## 一、审计结论

工具链基线（Gradle 9.5.1 / AGP 9.2.1 / Kotlin 2.2.10 / compileSdk 37 / minSdk 31 / M3 1.5.0-alpha22）完全合规；已知 Compose 陷阱组全部规避；组件动效与触控几何是三项目中**最精致**的（M3E 形变/波浪进度、48dp 触控底线、D 系列决策注释、图标解码防抖）。主要短板集中在：**签名口令入仓（红线）、深色冷启闪白、刷新清空列表、组合期无 remember 重算、破坏性操作确认缺口、i18n 漏网**。

## 三、修改意见（按优先级）

### 立即修（高收益/低成本）

1. **O-1 签名口令**：删除 `getOrElse(...)` 默认值，改为 Prunoid 式"凭据缺失回退 debug 签名保 CI"或 SDGun 式 assembleRelease fail-fast；**因默认口令已随历史入仓，若仓库已公开分发，同步轮换 keystore 口令**。
2. **O-2 刷新闪空**：`scanApps()` 去掉 `apps = emptyList()`，仅置 `isScanning = true`（Prunoid `AppViewModel.rescan()` 是现成样板，一处改动）。
3. **O-6 i18n 漏网**：4 处硬编码英文入 `values/strings.xml` + `values-zh-rCN/strings.xml`。
4. **O-4 删源确认**：`onDeleteSource` 前加 AlertDialog（复用本文件已有的 unsaved/master-off 对话框模式），两个订阅源区共用。
5. **O-11①桌面拷贝**：`packageAndBakeApk` 改为拷贝到项目归档目录（或仅保留 assembleDebug 产物在 build/，交付走发布渠道）。

### 近期修（小批量改动）

6. **O-5 深色闪白**：新增 `res/values-night/themes.xml` + `values(colors)/values-night(colors)` 的 `sdg_window_bg` 同款方案；照抄 `SDGun/android/app/src/main/res/values-night/themes.xml` 结构。
7. **O-3 列表过滤 remember**：`filtered`/`grouped` 用 `remember(state.apps, state.searchQuery, state.filterMode) { viewModel.applySearchAndFilter(...) }` 包裹（同文件 :500 的 displayIcons 是正确写法）。
8. **O-7 形变动画**：改为仅 `lsposedActive` 变化后播放 N 个周期即停，或降为低频呼吸（保留入场表达即可）。
9. **O-8 动作按钮标签**：编辑/删除/同步 IconButton 补 stringResource CD。
10. **O-10 失败判定**：SubscriptionManager 回调加结构化 `ok`/`severity` 位，UI 按位着色。

### 顺手清理

11. **O-9 死代码**：删除 StatusChip.kt、ParameterPanel.kt、MATERIAL_ICONS（删前再 grep 一次确认无反射/预览引用）。

## 六、跨项目协同事项（引自横评）

- SettingsCard/SettingItem/SectionTitle/CreditEntry/SearchField/RadioSheet/版本徽章/彩蛋与 Prunoid 已是两份互认复制（对方注释多处标注"OptIcon 样板"）；scrollingUp 两套实现各有缺陷——**第三个同类项目动工前抽共享模板**，滚动方向判定封装为 rememberLazyListState 派生扩展。
