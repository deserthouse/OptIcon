# OptIcon 产品契约（Product Contracts）

> 本文定义 OptIcon 用户可见行为的产品语义契约。每个概念给出**唯一可验证的行为定义**与**明确不承诺的内容**。UI 文案、状态表达与模块行为以本文为准；语义变更须先修订本文。
> 版本：2026-10-15（方案 B 阶段 0 首版，用户批准）。依据：架构评估报告 §2.2。

---

## 1. 「自动」= 当前所选来源内的自动处理

**定义**：任一策略内的"自动"，指在该策略**所选来源**内自动完成处理（分类、参数预置、键控或白化）。它**不**跨来源择优——OptIcon 不会替用户在规则库、图标包、自适应分层与兼容重绘之间挑选。

**不承诺**：已手选来源的素材缺失时，OptIcon 不静默切换到其他来源，而是明确提示缺失并引导换源。

**落点**：策略三「兼容重绘」文案（"任意图标自动重绘"= 分支内自动）；「恢复自动」按钮（见 §3）。

## 2. 「关闭自定义」= 回落规则库图标

**定义**（用户已批准，2026-10-15）：详情页「开启自定义通知图标」关闭后，该应用**回落规则库图标**——若 ANIP/规则库覆盖此应用，通知图标使用规则库版本；若无规则覆盖，保持系统原生通知图标。

**不承诺**：关闭≠"OptIcon 完全不介入此应用"——规则库仍可能接管（这是回落语义的一部分）。**完全跳过本模块**的能力由模块总开关（全局）或 LSPosed 中禁用模块承担，详情页不提供第三个选项。

## 3. 「恢复自动」= 仅重置当前处理路线参数

**定义**：「恢复自动」按钮只把**当前处理路线**的参数恢复为该路线的自动默认值。它**不**切换来源、**不**清除已上传素材、**不**改动色彩覆盖。

## 4. 色彩三概念（不要混淆）

| 概念 | 指什么 | 在哪里 |
|---|---|---|
| **素材原色** | 输入图片自身的颜色（重绘管线用于区分前景/背景，处理后不保留） | 兼容重绘的输入 |
| **输出类型** | OptIcon 烘焙产物当前全部为**单色剪影**（白色图形，供系统按通知栏底色染色） | 所有策略的输出 |
| **场景预览染色** | 状态栏预览中按深/浅底色给剪影着色的**展示效果**（深色栏→白、浅色栏→深），仅为预览 | 详情页预览卡 |

- 「保持原色」色彩覆盖选项修饰的是**通知系统行为**（OptIcon 不灰化此应用的通知图标），与输出类型无关。
- 兼容重绘上传的彩色图不因"预览染色"而表示最终通知是彩色的——最终通知图标由系统将单色剪影染色呈现。

## 5. 「已生效」证据阶梯

用户操作后，OptIcon 能给出的反馈**只到证据能支持的最深层级**：

| 证据 | UI 可以说 | UI 不可以说 |
|---|---|---|
| 配置持久写入成功 | 已保存 | 图标已显示 |
| 共享产物写入并校验成功 | 已保存并发布（等待运行端读取） | SystemUI 已使用该版本 |
| 模块心跳正常 | 模块运行连接正常 | 所有应用均已适配/替换 |
| 受控通知验证通过 | 该验证场景已生效 | 所有 ROM、所有通知形态全部通过 |

**落点**：保存成功反馈为"已保存并发布，该应用的新通知将使用新图标"（不写"立即"）；首页 Hero 卡以模块心跳为证据，现行文案为"模块已激活/模块连接正常"（不越级声明"替换已生效"——心跳证明 Hook 活性，不证明 SystemUI 已读取本次发布产物；2026-10-22 外审§7.5 勘误同步）。

## 6. UI 元素 ↔ 契约映射

| UI 元素 | 契约 |
|---|---|
| 详情页「开启自定义通知图标」 | §2：开=配置自定义替换；关=回落规则库（无规则则原生） |
| 策略三卡「兼容重绘」 | §1：分支内自动；文案随微调开关动态（关=全自动描述，开=可微调） |
| 重绘微调面板「恢复自动」 | §3 |
| 色彩策略行/选项 | §4：跟随全局/强制单色/保留原通知色彩 |
| 状态栏预览卡 | §4 场景预览染色 + 图例（单色剪影/半透明描边） |
| 保存成功反馈 | §5：已保存并发布 |
| 保存失败反馈 | §5：如实报错（守卫拒绝引导换源；配送失败可重试） |
| 首页 Hero 卡 | §5：心跳层证据（激活/未激活/检测中） |
